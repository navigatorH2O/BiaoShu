# 标枢（BiaoShu）

**让投标与交付文档的生产标准化、批量化、本地化**

标枢是一款面向投标、售前与软件交付场景的一体化 AI 文档生产工具箱。它把“招标文件解析 → 技术方案编写 → 标书检查 → 项目交付文档成套产出”整合到同一套本地工作流中，帮助团队用更短时间产出结构完整、内容可审、格式规范的文档。

---

## 一、产品定位

标枢不是简单的“AI 写作文档”，而是一套围绕招投标和项目交付设计的文档生产系统：

- 从招标文件出发，AI 理解项目要求，生成有依据的技术方案；
- 从项目清单出发，AI 成套产出交付文档，覆盖设计、数据库、接口、部署、手册与运维；
- 从本地出发，业务数据默认留在本机，文档资产可沉淀、可复用、可批量处理。

## 二、解决什么问题

| 痛点 | 标枢的做法 |
| --- | --- |
| 一份技术标动辄数万字，人工编写周期长 | 本地解析招标文件，AI 生成目录与正文，人工聚焦审核 |
| 目录、正文、格式反复调整 | 目录先审后写，正文分章节生成，支持自定义 Word 模板 |
| 每次项目都从零开始 | 项目上下文、知识库、历史方案均可复用 |
| 交付阶段还要补一套文档 | 批量导入项目清单，逐类生成 8 类交付文档 |
| 通用 AI 写出来像模板搬运 | 结合招标原文、项目清单和项目上下文写作，内容可追溯 |

## 三、核心功能

### 1. 标书生成

- 支持上传 PDF、Word、Excel、扫描件等招标文件，本地解析为结构化内容；
- 支持多标段识别与投标范围选择；
- AI 生成可编辑的树形目录，可拖拽、增删、调整层级；
- 正文按目录分章节生成，支持字数控制、表格生成、全文一致性审计；
- 一键导出 Word，支持自定义模板和排版配置。

### 2. 已有方案扩写

上传已有人工方案，AI 提取旧目录并补漏，在保留原方案真实内容的基础上扩写加厚，适合“方案太薄需要加厚”的场景。

### 3. 交付文档批量生成

批量导入项目清单（如项目收入/支出 Excel），每个文件作为一个项目，逐类生成 8 类交付文档：

1. 系统概要设计说明书；
2. 系统详细设计说明书；
3. 数据库 ER 图与表结构文档；
4. 全系统接口 API 文档；
5. 私有化部署拓扑图与网络架构图；
6. 分角色用户操作手册；
7. 运维管理手册；
8. 数据备份恢复操作文档。

每类文档都遵循“AI 生成目录 → 人工确认 → 生成正文 → 导出 Word”的流程，可跳过、可返回、可重试，每个项目独立保存进度。

### 4. 本地文件解析

- 本地解析 PDF、Word、Excel、TXT 等常用格式，不依赖外网；
- 复杂扫描件可接入 MinerU 精准 OCR；
- 解析结果统一转为 Markdown，供 AI 和知识库使用。

### 5. 知识库

- 管理文档资料、案例素材和可复用知识条目；
- 标书与交付文档生成时可引用知识库内容，让输出更贴合团队沉淀。

### 6. 标书检查

- 标书查重：目录、正文、图片相似度检测；
- 废标项检查：硬性条款与响应完整性核对；
- AI 评标：模拟 AI 评标视角，输出评分与改进建议。

### 7. 导出与模板

- 支持自定义 Word 模板与排版；
- Mermaid 图、HTML 配图在本地转换为 Word 图片，不依赖外网；
- 每个交付项目按输出目录批量导出，文档命名规范清晰。

### 8. 智能体双运行时

- 内置 OpenCode 与 Pi 两套智能体运行时，默认使用 OpenCode；
- 智能体在本地工作区执行多步骤任务，用于目录修复、一致性审计、原方案覆盖修复、补充审计等复杂环节；
- 数据与工具调用均在本机完成。

## 四、适用场景

- **投标团队**：快速编制技术方案、商务标，处理多项目、多标段；
- **售前与解决方案工程师**：从招标文件和项目材料中提炼要点，输出高质量方案；
- **系统集成商 / 软件公司**：项目交付时成套产出设计、数据库、接口、部署与手册文档；
- **交付与运维团队**：标准化产出操作手册、运维手册、备份恢复文档；
- **需要批量交付的团队**：一次导入多个项目，逐类生成并导出。

## 五、为什么选择标枢

- **本地优先，数据安全**：业务数据默认在本机处理，AI 请求只发送给用户自行配置的服务商；
- **从投标到交付一条线**：技术标、商务标、检查、交付文档全覆盖；
- **批量生产能力**：一个项目清单可以产出整套交付文档，多个项目可连续处理；
- **内容质量可控**：目录先审后写，正文可编辑，具备一致性审计与字数控制；
- **国产化适配**：面向统信 UOS、麒麟、达梦、人大金仓、鲲鹏、海光等场景做过适配规划；
- **开源可审计**：项目以 AGPL-3.0 开源，源码公开，可持续演进。

## 六、隐私与数据安全

- 招标文件、项目清单、生成方案与导出文件默认保存在本机；
- 配置的 API Key 只保存在本地配置文件中；
- 匿名埋点仅用于统计功能使用情况，不包含业务内容、文件名、路径与 API Key；
- 支持私有化部署方案，适合对数据敏感的企业客户。

## 八、技术架构

| 层 | 说明 |
| --- | --- |
| 客户端 | Electron 桌面应用，支持 Windows / macOS |
| 界面 | Vite + React + TypeScript，全局 CSS 与 Radix UI |
| 本地存储 | SQLite 工作区与本地文件缓存 |
| AI 能力 | 兼容 OpenAI 风格接口，支持 DeepSeek、火山方舟等文本模型与生图模型 |
| 智能体 | OpenCode / Pi 双运行时，本地多步骤任务 |
| 埋点 | Cloudflare 匿名统计，不含业务数据 |
